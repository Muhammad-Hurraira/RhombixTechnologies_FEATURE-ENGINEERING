# 📊 Rhombix Technologies – Feature Engineering Project

This project is a comprehensive exploration of **feature engineering techniques** essential for building effective machine learning models. Developed as part of an internship at **Rhombix Technologies**, it focuses on transforming raw data into meaningful inputs that improve model accuracy and performance.

---

## 🚀 What’s Included

- **Data Cleaning**: Handling missing values using imputation techniques (mean, median, mode, and domain-specific strategies).
- **Categorical Encoding**: One-hot encoding, label encoding, and ordinal encoding to prepare categorical features for modeling.
- **Feature Scaling**: Normalization and standardization using `MinMaxScaler`, `StandardScaler`, and `RobustScaler` to bring features to the same scale.
- **Feature Selection**: Techniques like correlation analysis, variance thresholding, and univariate selection to reduce dimensionality and retain important predictors.
- **Implementation in Python** using `pandas`, `NumPy`, `matplotlib`, `seaborn`, and `scikit-learn`.

---

- `RhombixTechnologies_FEATURE_ENGINEERING.ipynb`: Main notebook containing step-by-step explanation and implementation.
